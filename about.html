Svensk desktop-app för moderna jobbsökare

MyCareerKit

Hela jobbsökandet i en enda app

Sluta jonglera tio flikar. Hitta jobb, skapa perfekta ansökningar och skicka iväg dem – allt från din dator. MyCareerKit är den svenska desktop-appen som skapar ordning i kaoset.

MyCareerKit samlar hela den moderna jobbsökprocessen i ett enda, kraftfullt flöde. Hitta möjligheter, skapa skräddarsydda dokument med AI-hjälp och skicka ansökan – utan att lämna appen.

Problemet med dagens jobbsökande

Att söka jobb känns ofta som ett deltidsjobb i sig. Du letar på en sajt, skriver personligt brev i ett annat program, fixar CV:t i ett tredje och skickar mejl från ett fjärde. Det är massa friktion som suger musten ur dig och tar tid från det viktigaste: att faktiskt hitta rätt jobb.

Lösningen: En samlad arbetsyta för hela processen

Smart jobbsökning – alla källor på ett ställe

MyCareerKit kopplar direkt till Sveriges arbetsmarknad via Arbetsförmedlingens officiella JobTech API, kombinerat med vår egen kuraterade databas som hämtar jobb direkt från över 600 svenska arbetsgivares karriärsidor.

AI-drivna personliga brev som faktiskt är personliga

Mata in jobbannonsen och dina uppgifter, så skapar AI:n ett unikt brev som passar just den rollen. Men till skillnad från enkla mallar behåller du full kontroll: välj AI-leverantör (DeepSeek för maximal kraft, Groq för snabbhet, eller kör lokalt för total sekretess), justera kreativiteten och välj den stil som passar bäst. Slutredigera sedan i den inbyggda redigeraren innan du skickar.

Obegränsad CV-design utan mallbegränsningar

Inga färdiga mallar som låser in din kreativitet. Vår AI designar ett elegant CV från grunden, unikt för varje karriär. Välj mellan två lägen: Showstopper-läget skapar ett dynamiskt, animerat webb-CV (perfekt att länka till eller bifoga som HTML-fil) som fångar uppmärksamhet, eller Klassiskt läge för en ren, professionell PDF. Allt byggs i HTML/CSS. Med **direktvisuell redigering** anpassar du exakt vad du vill – bara klicka på elementet. Ingen kod behövs.

Ansök med ett klick – hela vägen till arbetsgivaren

Koppla säkert ditt Gmail via OAuth 2.0. När du är nöjd med din ansökan skickar du ditt skräddarsydda personliga brev och CV (som PDF eller länk) direkt till arbetsgivaren, allt inifrån appen. Inga kopieringsmoment, inga formatproblem, bara en smidig helhetslösning.

Tekniskt information

För dig som vill veta hur det fungerar bakom kulisserna. MyCareerKit är byggd med modern teknik för prestanda, säkerhet och flexibilitet.

Desktop-app med riktig prestanda

MyCareerKit är en äkta desktop-app byggd med Python 3 och PyQt6, inte en webbapp i fönsterförklädnad. Det betyder snabb respons, respekt för datorns resurser och inget konstigt beteende som du ibland ser i elektronbaserade appar.

Säkerhet och integritet i fokus

Vi tycker att du ska äga din egen jobbsökardata. All kryptering görs med cryptography-biblioteket, och när du använder externa tjänster som Gmail använder vi OAuth 2.0 via google-auth för säker åtkomst utan att vi någonsin ser dina lösenord.

Två datakällor för bästa täckning

Appen kombinerar Arbetsförmedlingens officiella JobTech-API med vår egen databas (MyCareerKit Job Database) som regelbundet hämtas direkt från svenska arbetsgivares karriärsidor. All data normaliseras till samma Job-objekt för konsistent sökning och filtrering.

Flexibel AI-arkitektur

Välj själv hur du vill använda AI: använd DeepSeek API för kraftfulla genereringar, Groq API för blixtsnabb respons, eller kör med en lokal LLM för total privatliv. Streaming responses visar text i realtid medan AI:n genererar.

Teknisk stack i sammanfattning

GUI: PyQt6 • PyQt6-WebEngine (för dokumentvisning)
Data: Pydantic (datavalidering) • JSON (konfiguration)
API: requests/httpx • Supabase (egen jobb-DB)
Säkerhet: cryptography • google-auth • PyJWT
AI: DeepSeek API • Groq API • streaming responses

Visionen bakom MyCareerKit

MyCareerKit är inte bara en CV-designer till. Det är en genomtänkt workflow-motor som tar bort allt onödigt krångel från ditt jobbsökande. Genom att samla hela processen – från första sökning till skickad ansökan – ger vi dig tillbaka det värdefullaste: din tid och ditt fokus.

MyCareerKit jobbar aktivt med tillgänglighet, inklusive skärmläsarstöd, för att jobbsökandet ska vara öppet för alla. Appen är byggd med en ren, händelsestyrda arkitektur som ser till att du får de mest kompletta och relevanta jobbannonserna utan väntetid.

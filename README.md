# MyCareerKit — Marketing Website

A marketing and demo website for **MyCareerKit**, a desktop application built for the Swedish job market. The site showcases the app's features through animations and interactive demos.

🔗 **Live site:** [adanessa.github.io/mycareerkit_web_4](https://adanessa.github.io/mycareerkit_web_4)

---

## Pages

- **Home** — Hero section and feature overview
- **Process** — Step-by-step walkthrough of how the app works
- **Gallery** — Screenshots and previews of the desktop app
- **CV Generator Demo** — Animated demo of the CV generation feature

## Tech Stack

- HTML5 / CSS3
- Vanilla JavaScript
- Hosted on GitHub Pages

## About MyCareerKit

MyCareerKit is a desktop app that helps users navigate the Swedish job market. Key features include:

- Job search aggregating 600+ Swedish employers
- AI-powered CV and cover letter generation
- Multiple AI provider support (OpenAI, Anthropic, Groq, DeepSeek)
- Export to PDF, DOCX, HTML and Markdown
